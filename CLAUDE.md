# TeamTrack — Citi Workshop

## Goal
Build a working employee-management app using the Citi workshop stack:
React, HTML/CSS, Material UI, responsive UI, Python API, MongoDB/DocumentDB,
Git/GitHub, shell scripts, Terraform, and AWS deployment.

## Working rules
- Read this file and AI_STATE.md before each task.
- Read only files relevant to the current task.
- Work on one small, end-to-end task at a time.
- Prefer the simplest working solution; avoid unnecessary dependencies and refactors.
- Explain important code briefly so a beginner can maintain it.
- Never overwrite unrelated work or perform destructive commands without approval.
- Never put secrets, API keys, passwords, or credentials in code or Git.
- Do not install heavy tools or dependencies without checking first.
- Do not claim tests, builds, or deployments succeeded unless actually verified.

## Task completion
After each completed task:
1. Run relevant tests/checks and report actual results.
2. Inspect git diff and summarize changed files.
3. Update AI_STATE.md with current status, verification, blockers, and one next task.
4. Update ROADMAP.md only when milestones change.
5. Do not commit or push unless the user asks or approves.

## Token efficiency
- Avoid rereading the whole repository or repeating project history.
- Keep AI_STATE.md concise.
- Ask before expanding scope or adding major dependencies.
- If blocked, report the exact issue and the smallest next action.
